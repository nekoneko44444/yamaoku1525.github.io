協同組合阿波山雅 Webサイト 設計書（v0.1）

このページは、今後の改修を進めるための共通設計メモです。まず現状のページ構成を整理し、その上で新しい情報設計（IA）と運用ルールを定義します。

1. 目的

  • ページの役割重複を減らし、閲覧者が迷わない導線にする。
  • 更新頻度の高い情報（ニュース・活動報告）を分離し、運用しやすくする。
  • この設計書を元に、以後の改修を「手動指示」で段階的に進められる状態にする。

2. 現状ページ構成（2026-05-27時点）

ページ主な役割課題メモ
index.htmlトップページ情報量が多く、初見での優先導線が分散しやすい。
about.html団体紹介理念・沿革・体制の粒度を今後そろえる余地あり。
facility_guide.html施設案内アクセス、予約、利用案内のセクション分割を強化したい。

news.html / news.jsonお知らせ一覧データ更新フロー（誰が・いつ・どう編集）を明確化したい。

3. 改訂後の推奨情報設計（IA案）

案A現行ページを活かしつつ、役割を明確化する。

  • ホーム：概要・主要導線のみ（詳細は下層へ）。
  • 阿波山雅について：理念 / 体制 / 沿革 / ミッションを集約。
  • 活動：projects.html（取り組みの静的説明）とactivity-report.html（時系列報告）を明確分離。
  • 施設案内：利用案内・アクセス・FAQ中心に再整理。
  • 応援する：個人支援・法人協賛・問い合わせを1ページで完結。
  • お知らせ：更新性の高い短文情報を集約。

4. ナビゲーション見直し方針

  1. グローバルナビの項目は最大7〜8項目に維持。
  2. 「活動」と「報告」の違いをラベルで明示（例：活動紹介 / 活動報告）。
  3. 各ページの冒頭に1行説明を置き、ページ目的を明確化。
  4. フッターナビはグローバルナビと原則同期。

5. 手動指示での改修運用ルール

以後は次のテンプレで指示すると、段階的に改修しやすくなります。

指示テンプレ例
[対象ページ] [対象セクション] [やりたい変更] [優先度] projects.html ヒーロー文言を3案出して、2案目を反映。優先度高。
  • 1回の指示は「1ページ or 1テーマ」に絞る。
  • 文言修正かレイアウト修正かを最初に指定する。
  • 迷う場合は「提案だけ先に」と書く（未反映案として返す）。

6. 次アクション候補

  1. トップページの導線優先順位を確定（例：活動 → 支援 → 施設）。
  2. projects.html / activity-report.html の役割文を冒頭に追加。
  3. support.html に問い合わせ導線（ボタン）を強化。
